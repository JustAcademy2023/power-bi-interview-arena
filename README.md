# Power BI Interview Arena

**Power BI interview questions and DAX concepts for data analysts, played as a five level game.**

A single page landing site that turns interview preparation into something you actually want to open. Work through five levels, borrow from the DAX lab, and take on four scenario boss fights, all written for data analysts in Pune who want clear answers instead of memorised scripts.

## What is inside

The page is one self contained `index.html` with no build step and no dependencies beyond Google Fonts.

- **Five levels** covering Power BI basics, data modelling, DAX concepts, Power Query and cloud, and dashboards with scenarios. Each level has tap to reveal interview answers.
- **The DAX Lab** with five copy ready measures: total sales with an iterator, sales last year, share of total, growth with variables and product ranking.
- **Boss fights** for project management dashboards, marketing data analytics, product analytics and slow report troubleshooting.
- **Power ups** linking to live, mentor led training for Pune learners.
- **Quick answers** written for readers and for search assistants, backed by FAQ structured data.
- A scroll progress bar, animated hero chart, responsive layout and reduced motion support.

## Topics covered

Power BI interview questions, how to crack a Power BI interview, DAX concepts, row context and filter context, CALCULATE, time intelligence, star schema, Power Query, query folding, Power BI Service and cloud, Power BI reporting, Power BI for project management, marketing data analytics, product analytics and data analytics tools.

## Run it locally

Open `index.html` in any modern browser. Nothing to install.

## Publish on GitHub Pages

1. Push `index.html` and `README.md` to the root of your repository.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your site goes live at `https://your-username.github.io/power-bi-interview-arena/` within a minute or two.
